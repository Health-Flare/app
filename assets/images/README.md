# README/repo display images

Not bundled into the app (see `pubspec.yaml`'s `assets:` — this folder
isn't listed). Purely for GitHub display.

- `health-flare-banner.png` — the README header. Built from
  [Health-Flare/brand](https://github.com/Health-Flare/brand)@`v2.0.0`'s
  "moment" graphic (`moment/healthflare-moment-sunrise.svg`), Sunrise on
  Dawn, with the horizon run out to the canvas edges (brand-guidelines.md
  explicitly allows this in wide formats). No wordmark is typeset: the
  brand kit's outlined lockup files don't exist yet, and the guidelines
  say not to set the wordmark live until they do.

If the brand updates, rebuild this from the brand repo rather than
hand-editing it.
