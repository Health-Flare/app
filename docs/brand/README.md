# Brand assets

Health Flare product assets, selected for this app. Canonical source, full
guidelines, and the complete kit (including Inner Flare's assets, the brand
moment graphic, and favicons this repo doesn't need) live in
[Health-Flare/brand](https://github.com/Health-Flare/brand), pinned here to
[`v2.0.0`](https://github.com/Health-Flare/brand/releases/tag/v2.0.0).

- `marks/` — `healthflare-mark-<size>-<colour>.svg`, all three optical sizes
  (`full`/`compact`/`micro`) × four colours (`sunrise`/`ink`/`white`/`amber`),
  for light/dark UI theming.
- `app-icons/` — the 1024px App Store/Play Store masters, plus the `-dark` and
  `-android-monochrome` variants.

Not included (not used by this app): Inner Flare's assets, the brand moment
graphic (marketing/large-surface only), favicons (no web target here).

Read the full rules — optical size ranges, clear space, colour contrast,
do/don't — in [`brand-guidelines.md`](https://github.com/Health-Flare/brand/blob/v2.0.0/brand-guidelines.md)
before wiring these into the app icon pipeline or in-app theming.
