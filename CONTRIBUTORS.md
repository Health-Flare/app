# Contributors

Code contributions are credited automatically. Everyone who has committed to this repository shows up in [GitHub's contributor list](https://github.com/Health-Flare/app/graphs/contributors).

A lot of the work on Health Flare never lands as a commit: testing builds, reporting bugs, reviewing medical or clinical wording, design, translation, accessibility checks, and telling us how the app holds up on a bad day. That work doesn't show up anywhere on GitHub, so it's credited here by hand.

## Adding someone

Open a PR that adds a line under "Other contributions", or ask in an issue and a maintainer will add it. One line per person, in the order they were added:

```markdown
- **Name** ([@handle](https://github.com/handle)): what they did.
```

The link is optional. A few rules, because this is a health project and some contributors are patients or carers:

- Only list someone who has agreed to be named, under the name they chose. A first name or a handle is fine.
- Describe the contribution, not the person. Never mention a health condition, diagnosis, or family detail unless they've asked for it to be there.
- If someone asks to be removed, remove them. No questions.
